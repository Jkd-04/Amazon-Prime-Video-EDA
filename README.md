# Amazon Prime Video – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on Amazon Prime Video's titles and credits datasets to understand the platform's content catalogue, distribution, diversity and trends.

## Business Objectives
- Analyse the distribution of movies and TV shows.
- Identify the most represented genres.
- Examine content release trends over the years.
- Explore production-country contributions.
- Analyse IMDb ratings, TMDB scores and popularity indicators.
- Examine actor and director participation.
- Generate meaningful insights to support content strategy.

## Tools and Technologies
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly

## Project Workflow
1. Data Loading and Inspection
2. Data Cleaning and Preprocessing
3. Missing Value and Duplicate Analysis
4. Univariate Analysis
5. Bivariate Analysis
6. Correlation Heatmap and Pair Plot
7. Business Insights and Recommendations
8. Conclusion

## Datasets
- `titles.csv` – Contains title information, content type, release year, genres, production countries, runtime and rating indicators.
- `credits.csv` – Contains cast and crew information, including actors and directors.

## Key Deliverables
The project explores content distribution, genre representation, geographical contributions, release patterns, rating relationships and creative talent participation.

## Limitations
The datasets do not contain actual Prime Video viewership, subscriber engagement, revenue or content acquisition costs. IMDb and TMDB metrics are external indicators and should not be interpreted as direct platform performance measures.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook in Google Colab or Jupyter Notebook.
4. Ensure the datasets are available at the paths specified in the notebook.
5. Run the notebook cells sequentially.
